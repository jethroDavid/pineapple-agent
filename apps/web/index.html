How it works

The runtime stays deliberately narrow.

01

Agents are files

Each specialist is declared in JSON with its prompt, tools, handoffs, and hosted OpenAI tools.

02

Runs are durable

Threads, decisions, and checkpoints are stored so interrupted work can resume without guessing.

03

Codex handles code

Repository inspection, shell commands, edits, and validation stay inside a dedicated coding specialist.

04

Adapters are scoped

Telegram, Shortcut, cron scheduling, and mobile audio are exposed only where the manifest allows them.
